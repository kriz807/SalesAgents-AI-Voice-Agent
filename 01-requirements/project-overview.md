# SalesAgents AI – Voice Agent Assignment

## Project Overview
This project focuses on creating an AI voice agent for Home Credit. The agent will speak with existing customers about a pre-approved Loan Against Property (LAP) offer and collect the information needed for preliminary eligibility screening.

## Main Objective
The goal is to make the conversation feel natural while ensuring that the agent follows the required eligibility rules.

## What the Agent Should Do
- Verify the customer before discussing the offer.
- Check whether the customer is available to talk.
- Explain the Loan Against Property offer.
- Identify customers with an existing property loan or EMI-reduction request.
- Collect all seven required eligibility items.
- Remember information provided earlier in the conversation.
- Stop the qualification process when a customer fails a mandatory criterion.
- Refer customers who pass all preliminary checks to a senior loan expert.

## Important Rules
- Maximum loan amount: INR 75 lakh.
- Eligible property types: Residential, Commercial, Industrial.
- Agricultural properties are not eligible.
- Sole and joint ownership are accepted.
- Original property documents must be available.
- Income must be received through a bank, not only in cash.
- Accepted loan tenure: 3 to 15 years.
- Property market value must be collected without inventing a minimum threshold.
- Customers requesting more than INR 75 lakh must be offered the INR 75 lakh option before ending the call.
- Exact interest rates must not be invented.

## Expected Deliverables
1. Complete system prompt.
2. Test call recordings.
3. Transcripts for each recording.
4. Explanation of the implementation and testing approach.
5. Final submission links and files.

## Development Approach
First, understand the requirements and design the conversation flow. Then write the system prompt, configure the voice-agent platform, test different customer scenarios, improve the agent, and prepare the final submission.
